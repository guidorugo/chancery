A profile fixes the Key Usage / Extended Key Usage of the certificates issued under it and can bound validity, key type and size, and SAN types. It is enforced server-side, for the forms and the API alike. Custom carries no restriction beyond the global policy. Built-in profiles can be edited and disabled but not deleted; each CA may additionally restrict which profiles it issues under (on the CA page).
