Authenticate before you try anything

Use Authorize with an API token (recommended: scoped, expiring, works with two-factor accounts, and a typo cannot lock your account) or your username and password. Try it out never uses your browser session: a call without Authorize is answered with 401, and nothing you enter is stored.

Scripts: curl -H "Authorization: Bearer chy_api_…" -H "Accept: application/json" {{ url_for('ca.list_cas') }}

Executing calls here is real

Every request runs against this Chancery and is audited like any API call. Operations marked returns private-key material display the key in the response panel on this screen — use curl for those unless that is what you intend.
